# **AI 기반 이미지 보정 애플리케이션 기획서 (ImgGlow AI)**

---

## **1. 프로젝트 개요**

### **1.1 프로젝트명**

**ImgGlow AI**

### **1.2 프로젝트 목적**

본 프로젝트는 모바일 환경에서 사용자가 이미지를 업로드하고, 인공지능 기반 이미지 보정 기능을 통해 화질을 개선할 수 있는 애플리케이션을 설계 및 구현하는 것을 목적으로 한다.

사용자는 별도의 전문적인 이미지 편집 도구 없이도 간단한 조작만으로 업스케일링, 디블러링, 배경 분리 기능을 활용하여 이미지 품질을 향상시킬 수 있다.

또한 FastAPI 기반 서버와 오픈소스 딥러닝 모델을 연동하여 실제 서비스 형태의 AI 이미지 처리 시스템을 구현하는 것을 목표로 한다.

### **1.3 기대 효과**

* 비전문 사용자도 손쉽게 이미지 품질 개선 가능
* AI 기반 이미지 처리 기술의 실용적 활용 경험 제공
* 모바일 클라이언트와 서버 기반 AI 추론 시스템 연동 구조 이해

---

## **2. 시스템 개요**

### **2.1 시스템 구성**

본 시스템은 모바일 클라이언트, API 서버, AI 추론 모듈로 구성된다.

* **모바일 클라이언트 (React Native)**
  사용자 인터페이스 제공, 이미지 업로드 및 결과 확인

* **API 서버 (FastAPI)**
  이미지 처리 요청 관리 및 작업 기록 저장

* **AI 추론 모듈 (Python 기반)**
  선택된 기능에 따라 이미지 처리 수행

---

### **2.2 시스템 처리 흐름**

1. 사용자가 이미지를 선택하여 업로드한다.
2. 사용자가 원하는 보정 기능을 선택한다.
3. 모바일 앱이 FastAPI 서버에 이미지 처리 요청을 전송한다.
4. 서버는 요청에 따라 해당 AI 모델을 실행한다.
5. 처리 결과를 저장하고 클라이언트에 반환한다.
6. 사용자는 결과 화면에서 원본과 결과를 비교하고 저장할 수 있다.

---

### **2.3 기술 스택**

#### **클라이언트**

* React Native
* React Navigation

#### **서버**

* FastAPI
* Python

#### **AI 모델**

* **Real-ESRGAN**: 이미지 업스케일링
* **Restormer**: 이미지 디블러링 (손떨림 제거)
* **BiRefNet Tiny**: 이미지 배경 분리

#### **데이터 관리**

* JSON 파일 기반

## **4. 화면 설계**

### **4.1 홈 화면**

* 이미지 업로드 기능
* 이미지 미리보기
* 기능 선택 버튼
* 처리 실행 버튼

### **4.2 결과 화면**

* 결과 이미지 출력
* 원본 및 결과 비교 기능
* 처리 전후 이미지 크기 표시
* 결과 저장 기능
* 홈 화면 이동 기능

### **4.3 기록 화면**

* 작업 목록 조회
* 기능 종류 및 상태 표시
* 작업 상세 결과 확인

---

## **5. API 설계**

### **5.1 이미지 처리 API**

* `POST /process/upscale`
* `POST /process/deblur`
* `POST /process/remove-bg`

### **5.2 작업 기록 API**

* `GET /history`
* `GET /history/{id}`
* `PATCH /history/{id}`
* `DELETE /history/{id}`

---

## **6. 데이터 설계**

### **6.1 작업 기록 데이터 구조**

* **id**: 작업 식별자
* **userId**: 사용자 식별자
* **type**: 처리 기능 종류
* **status**: 작업 상태 (processing, completed)
* **originalImage**: 원본 이미지 경로
* **resultImage**: 결과 이미지 경로
* **originalSize**: 원본 이미지 크기
* **resultSize**: 결과 이미지 크기
* **createdAt**: 생성 시각

## **7. 요구사항 정의**

### **7.1 기능 요구사항**

1. 사용자는 이미지를 선택하여 업로드할 수 있어야 한다.
2. 사용자는 업스케일링, 디블러링, 배경 분리 기능 중 하나를 선택할 수 있어야 한다.
3. 시스템은 선택된 기능에 따라 적절한 AI 모델을 실행해야 한다.
4. 시스템은 이미지 처리 진행 상태를 사용자에게 표시해야 한다.
5. 시스템은 처리 완료 후 결과 이미지를 사용자에게 제공해야 한다.
6. 사용자는 원본 이미지와 결과 이미지를 비교할 수 있어야 한다.
7. 사용자는 결과 이미지를 저장할 수 있어야 한다.
8. 시스템은 작업 기록을 저장하고 조회할 수 있어야 한다.
9. 사용자는 작업 기록을 삭제할 수 있어야 한다.

---

### **7.2 비기능 요구사항**

#### **성능 요구사항**

* 이미지 처리 요청은 합리적인 시간 내에 완료되어야 한다.
* 사용자 인터페이스는 지연 없이 동작해야 한다.

#### **사용성 요구사항**

* 주요 기능은 최소한의 조작으로 실행 가능해야 한다.
* 직관적인 UI를 제공하여 사용 편의성을 확보해야 한다.

#### **안정성 요구사항**

* 서버 오류 발생 시 적절한 오류 메시지를 제공해야 한다.
* 처리 실패 시 작업 상태를 기록해야 한다.

#### **확장성 요구사항**

* 추가 이미지 처리 기능을 쉽게 확장할 수 있어야 한다.
* 데이터 저장 구조는 DB 기반으로 확장 가능해야 한다.
