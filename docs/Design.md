# ImgGlow AI 디자인 컨셉

## 프로젝트 방향
ImgGlow AI의 프론트엔드는 일반적인 유틸리티 앱보다 "프리미엄 AI 이미지 스튜디오"에 가까운 인상을 목표로 한다. 사용자가 이미지를 업로드하고 결과를 비교하는 흐름이 중심이기 때문에, 배경과 보조 영역은 차분하게 두고 이미지와 핵심 액션 버튼이 먼저 보이도록 설계한다.

## 핵심 분위기
- 시네마틱하고 밀도감 있는 다크 톤
- 차분하지만 강한 존재감이 있는 에디토리얼 무드
- 도구형 앱답게 정보 위계가 분명한 레이아웃
- 지나치게 장식적이지 않고, 결과 이미지가 중심이 되는 화면 구성

## 컬러 팔레트
- **Primary Crimson `#BF0436`**
  주요 CTA, 활성 상태, 핵심 강조에 사용하는 대표 색상
- **Deep Wine `#73020C`**
  눌림 상태, 깊은 강조 톤, 다크 무드 보강에 사용하는 보조 색상
- **Soft Rose `#D9A0AF`**
  상태 배지, 보조 강조, 선택 상태 표현에 사용하는 포인트 색상
- **Warm Neutral `#D9CEC5`**
  제목 보조, 카드 내부 대비, 부드러운 균형감을 주는 중립 색상

## 화면별 컨셉
### Home
- 서비스 성격이 바로 보이도록 헤더 카피와 작업 흐름을 먼저 제시한다.
- 이미지 선택, 기능 선택, 처리 실행 순서가 자연스럽게 읽히도록 세로 리듬을 유지한다.
- 기능 선택 카드는 동일 구조로 정리하되 활성 상태만 컬러와 그림자로 분명히 구분한다.

### Result
- 처리 상태와 결과 확인을 한 화면에서 빠르게 읽을 수 있도록 상태 카드 중심 구조를 사용한다.
- 원본과 결과 이미지는 같은 카드 문법으로 정렬해 비교 흐름을 단순하게 유지한다.
- 저장, 기록 보기, 홈 이동 액션은 중요도 순서대로 톤을 나눈다.

### History
- 작업 기록은 정보 카드형 리스트로 보여주고 상태 배지로 완료 여부를 즉시 파악할 수 있게 한다.
- 메타데이터는 작고 정돈된 텍스트로 처리해 기록성 화면의 성격을 살린다.
- 빈 상태에서도 어색하지 않도록 안내 문구를 간결하게 유지한다.

## 컴포넌트 원칙
- 버튼은 둥근 pill 형태를 기본으로 한다.
- 카드 구분은 강한 선 대신 배경 톤 차이와 그림자로 만든다.
- 이미지 영역은 크게 둥근 모서리로 통일해 결과물이 부드럽게 드러나도록 한다.
- 텍스트는 제목, 설명, 메타 정보 3단계 위계를 유지한다.

## 레이아웃 원칙
- 주요 섹션 사이에는 충분한 여백을 둔다.
- 한 화면 안에서 "설명 → 미리보기 → 선택 → 실행" 흐름이 끊기지 않게 배치한다.
- 모바일에서 빠르게 스캔할 수 있도록 텍스트 폭과 카드 폭을 안정적으로 유지한다.
