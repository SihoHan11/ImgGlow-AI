# Design System: ImgGlow AI Mobile
**Project ID:** 17198042925193149072

## 1. Visual Theme & Atmosphere
ImgGlow AI의 모바일 화면은 일반적인 유틸리티 앱보다 "프리미엄 AI 스튜디오"에 가깝다. 전체 분위기는 깊고 따뜻한 다크 톤 위에 절제된 크림슨 포인트를 얹은 시네마틱 에디토리얼 스타일이며, 이미지 결과물이 가장 먼저 돋보이도록 차분한 레이어 구조를 유지한다.

## 2. Color Palette & Roles
- **Crimson Core (#BF0436):** 주요 실행 버튼, 활성 상태, 핵심 CTA에 사용하는 대표 색상.
- **Deep Wine (#73020C):** 어두운 강조 배경, 버튼 눌림 상태, 강한 대비가 필요한 영역에 사용하는 보조 색상.
- **Soft Rose Mist (#D9A0AF):** 선택 상태, 설명 텍스트 강조, 상태 배지의 부드러운 포인트 톤.
- **Warm Bone (#D9CEC5):** 카드 내부의 중립 포인트와 밝은 텍스트 대비를 보조하는 뉴트럴 톤.
- **Onyx Surface (#17120D):** 앱 전체 기본 배경. 검정보다 따뜻하고 밀도감 있는 바탕 역할.
- **Layered Cocoa (#241F19 / #2F2923 / #3A342D):** 카드, 선택 패널, 강조 박스에 쓰는 단계별 표면 색상.

## 3. Typography Rules
제목은 밀도감 있게, 본문은 짧고 명확하게 구성한다. 큰 제목은 굵은 웨이트로 강한 위계를 주고, 보조 설명은 채도를 낮춘 밝은 텍스트를 사용해 시선 분산을 줄인다. 메타 정보는 본문보다 한 단계 작은 크기로 배치해 "도구형 UI"의 정돈감을 유지한다.

## 4. Component Stylings
* **Buttons:** 둥근 pill 형태를 기본으로 사용한다. 주 버튼은 Crimson Core 기반의 강한 대비를 사용하고, 보조 버튼은 어두운 반투명 표면 위에 밝은 텍스트를 올린다.
* **Cards/Containers:** 흰 배경 대신 코코아 계열의 다층 표면을 사용한다. 경계선은 최소화하고 색면 차이와 그림자로 레이어를 구분한다.
* **Inputs/Forms:** 강한 선보다 배경 톤 변화와 여백으로 구획한다. 선택 상태는 크림슨 또는 로즈 계열로 표시한다.
* **Image Frames:** 이미지 컨테이너는 크게 둥근 모서리를 사용해 결과물이 부드럽게 떠오르는 느낌을 만든다.

## 5. Layout Principles
주요 섹션 사이에는 넉넉한 간격을 두고, 한 화면 안에서 "헤더 → 핵심 미리보기 → 선택 영역 → 실행 액션" 흐름이 끊기지 않도록 세로 리듬을 유지한다. 카드와 버튼은 화면 폭을 안정적으로 채우되, 텍스트 블록은 너무 넓어지지 않게 묶어 모바일에서 빠르게 스캔되도록 한다.
